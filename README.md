# Transport SQL Analysis

## Project Overview

SQL-based analysis of public transport data to understand routes, trips, passengers, revenue, and delays.

## Database Tables

- `routes` – Route details, source, destination, and distance
- `trips` – Trip, route, bus, driver, and timing details
- `passengers` – Passenger count, ticket revenue, boarding and dropping information
- `stop_times` – Arrival and departure times
- `delays` – Delay duration and delay reasons

## SQL Concepts

- SELECT
- WHERE
- ORDER BY
- GROUP BY
- HAVING
- JOIN
- CASE WHEN
- Subqueries
- CTE
- Window Functions
- Ranking

## Analysis

The project focuses on:

- Identifying high-demand routes
- Analyzing passenger movement
- Analyzing ticket revenue
- Finding peak travel periods
- Analyzing transport delays
- Evaluating route performance
- Generating business insights
